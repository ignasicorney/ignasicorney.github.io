✏️ Editor del web

Obre el web ↗

Seccions i blog d'ignasicorney.github.io. En desar, els canvis es publiquen en un o dos minuts.

🔒 Clau

Com aconsegueixo la clau?
  1. Entra a GitHub amb el compte ignasicorney i obre aquesta pàgina.
  2. Nom: «Editor del web». Caducitat: la més llarga que et deixi.
  3. A «Repository access», tria Only select repositories i marca ignasicorney.github.io.
  4. A «Permissions → Repository permissions», posa Contents a Read and write.
  5. Clica «Generate token», copia la clau i enganxa-la aquí. Si la marques per recordar, no te la tornarà a demanar en aquest navegador.

Veure la pàgina ↗
